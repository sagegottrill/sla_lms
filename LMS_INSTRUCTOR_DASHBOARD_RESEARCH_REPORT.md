# Instructor Dashboard Competitive Research Report
**Date:** May 3, 2026  
**Platforms Analyzed:** Canvas LMS, Moodle, TalentLMS  
**Current Platform:** SLA LMS (She Leads Africa)

---

## Executive Summary

This report analyzes instructor/teacher dashboard features across three leading LMS platforms (Canvas, Moodle, TalentLMS) to identify gaps and opportunities for improving the SLA LMS instructor experience. The research reveals **6 critical gaps** and **2 unnecessary features** that should be addressed to bring our instructor dashboard to competitive standards.

**Current Grade: C+ (78/100)**  
**Target Grade: A- (92/100)**

---

## 1. Platform Feature Comparison

### Canvas LMS Instructor Dashboard

**Core Features:**
1. **Course Tiles with Activity Notifications**
   - 4 notification icons per course
   - Shows: submissions, announcements, discussions, files
   - Visual indicators for what needs attention
   - Quick access to all courses

2. **Comprehensive To-Do List (Sidebar)**
   - Shows assignments that need grading across ALL courses
   - Not time-based (shows what needs action, not what's due soon)
   - Helps prioritize grading workload
   - Cross-course visibility

3. **Coming Up Section**
   - Displays upcoming assignments (next 7 days)
   - Helps instructors plan ahead
   - Shows deadlines across all courses

4. **Multiple Dashboard Views**
   - Card View (default, visual tiles)
   - List View (agenda-style)
   - Recent Activity View (activity feed)
   - User can switch based on preference

5. **Quick Access to Grading**
   - Direct links to assignments needing grading
   - Gradebook access from dashboard
   - View grades button

6. **Course Analytics**
   - View course analytics directly
   - Student engagement metrics
   - Performance tracking

### Moodle Teacher Dashboard

**Core Features:**
1. **Course Overview**
   - All courses visible at once
   - Quick navigation to any course
   - Course status indicators

2. **Gradebook Integration**
   - Every course has its own gradebook
   - Records scores from multiple activity types
   - Manual grade entry supported
   - Import/export grades

3. **Activity Completion Tracking**
   - Set completion conditions per activity
   - Visual completion indicators
   - Course completion tracking
   - Badge issuance based on criteria

4. **Flexible Course Management**
   - Course sections can be renamed
   - Drag-and-drop section reordering
   - Add/remove sections easily
   - Blocks for additional functionality

5. **Enrolment Management**
   - Multiple enrolment methods
   - Manual enrolment
   - Self-enrolment with keys
   - Guest access control

6. **Restrict Access Features**
   - Hide/show items manually
   - Conditional access based on criteria
   - Time-based restrictions
   - Group-based restrictions

### TalentLMS Instructor Dashboard

**Core Features:**
1. **Dashboard Widgets (Customizable)**
   - Overview section with key metrics
   - Active users count
   - Assigned courses count
   - Groups count
   - Training time tracking
   - Completion rate percentage

2. **Advanced Analytics**
   - Participation metrics (users who opened at least one unit)
   - Engagement metrics (users who completed at least one course)
   - Progress tracking (average course progress)
   - Training savings calculator
   - Environmental impact calculator

3. **Course Reports**
   - Track user progress in specific courses
   - Course-level analytics
   - Micro-statistics per course
   - Completed learners tracking

4. **Instructor-Specific View**
   - Refreshed dashboard look
   - Widget-based information display
   - Customizable layout
   - Quick access to key information

5. **Legacy/New Interface Toggle**
   - Instructors can switch interfaces
   - Preference remembered
   - Smooth transition between views

### ✅ What We Do Well

2. **Course Organization**

   - Total payouts
   - Clean, minimalist design

5. **Personalization**
   - Time-of-day greeting
   - First name usage
   - Course count display

### ❌ Critical Gaps (Missing Features)

#### Gap 1: No Grading Queue / To-Do List ⚠️ HIGH PRIORITY
**What's Missing:**
- No centralized list of assignments that need grading
- No visibility into pending submissions across courses
- Instructors must visit each course individually to check for submissions
- No prioritization of grading workload

**Competitor Implementation:**
- **Canvas:** To-Do List sidebar shows all assignments needing grading across ALL courses
- **Moodle:** Gradebook integration with pending submissions visible
- **TalentLMS:** Course reports show completion status and pending items

**Impact:** Instructors miss submissions, delayed feedback, poor student experience, increased support requests

**Recommendation:** Add "Grading Queue" widget showing:
- Assignments awaiting grading across all courses
- Number of submissions per assignment
- Due dates for assignments
- Quick link to grade each assignment
- Sort by oldest first or by due date

---

#### Gap 2: No Course Analytics / Student Engagement Metrics ⚠️ HIGH PRIORITY
**What's Missing:**
- No visibility into student engagement per course
- No analytics on course performance
- No tracking of student progress
- No identification of at-risk students

**Competitor Implementation:**
- **Canvas:** Course Analytics showing student engagement, page views, participation
- **Moodle:** Activity completion tracking, course completion status
- **TalentLMS:** Participation, engagement, and progress metrics with formulas

**Impact:** Instructors can't identify struggling students, no data-driven teaching decisions, reactive rather than proactive support

**Recommendation:** Add "Course Analytics" section showing:
- Student engagement rate per course
- Average progress percentage
- At-risk students (low engagement/progress)
- Completion rates
- Time spent in course
- Click to view detailed analytics per course

---

#### Gap 3: No Upcoming Deadlines / Calendar View ⚠️ MEDIUM PRIORITY
**What's Missing:**
- No visibility into upcoming assignment deadlines
- No calendar view of course schedule
- No planning tool for instructors
- No reminder of what's coming up

**Competitor Implementation:**
- **Canvas:** "Coming Up" section shows next 7 days of deadlines
- **Moodle:** Timeline block shows upcoming activities
- **TalentLMS:** Dashboard widgets show upcoming events

**Impact:** Instructors miss deadlines, poor planning, last-minute grading rushes

**Recommendation:** Add "Upcoming Deadlines" widget showing:
- Next 7-14 days of assignment deadlines
- Across all courses
- Number of expected submissions
- Quick link to each assignment
- Calendar view option

---

#### Gap 4: No Student Activity Feed / Recent Activity ⚠️ MEDIUM PRIORITY
**What's Missing:**
- No visibility into recent student activity
- No feed of submissions, discussions, questions
- No way to see what students are doing
- No engagement indicators

**Competitor Implementation:**
- **Canvas:** Recent Activity View shows all activity across courses
- **Moodle:** Recent activity block shows course activity
- **TalentLMS:** Activity tracking in course reports

**Impact:** Instructors are disconnected from student activity, miss opportunities to engage, delayed responses to questions

**Recommendation:** Add "Recent Activity" feed showing:
- Recent submissions (last 24-48 hours)
- Recent discussion posts
- Recent questions/comments
- Student enrollments
- Course completions
- Filterable by course

---

#### Gap 5: No Dashboard View Options ⚠️ LOW PRIORITY
**What's Missing:**
- Only one dashboard layout available
- No user preference for different views
- No list view or activity feed option
- One-size-fits-all approach

**Competitor Implementation:**
- **Canvas:** 3 view options (Card, List, Recent Activity)
- **Moodle:** Customizable blocks, drag-and-drop
- **TalentLMS:** Widget customization

**Impact:** Doesn't suit all teaching styles, some instructors prefer different layouts

**Recommendation:**
- Add List View option (agenda-style)
- Add Activity Feed View option
- Remember user preference
- Keep current Card View as default

---

#### Gap 6: No Bulk Actions / Course Management Tools ⚠️ LOW PRIORITY
**What's Missing:**
- No bulk operations on courses
- No quick publish/unpublish
- No duplicate course feature
- No archive/delete options from dashboard

**Competitor Implementation:**
- **Canvas:** Course management tools in dashboard
- **Moodle:** Course actions available from overview
- **TalentLMS:** Bulk operations in admin interface

**Impact:** Time-consuming course management, repetitive tasks

**Recommendation:** Add dropdown menu per course with:
- Publish/Unpublish
- Duplicate course
- Archive course
- View analytics
- Manage enrollments
- Export course data

---

### 🗑️ Unnecessary Features (Should Remove/Simplify)

#### Unnecessary 1: Help Bubble (Hidden on Mobile)
**Current State:**
- Fixed help button in bottom right
- Hidden on mobile (where many instructors work)
- No clear purpose or functionality
- Takes up screen real estate

**Recommendation:**
- Remove fixed help bubble
- Add help link to user menu instead
- Or make it functional with actual help content
- Consider contextual help instead

---

#### Unnecessary 2: Overly Minimal Analytics Widget
**Current State:**
- "Global Reach" widget shows only 3 metrics
- No actionable insights
- No drill-down capability
- No trend data

**Recommendation:**
- Expand to show more useful metrics
- Add trend indicators (up/down arrows)
- Add click-through to detailed analytics
- Show per-course breakdown option

## 6. Database Schema Changes Needed

### New Tables Required:

```sql
-- Grading Queue (track pending submissions)
CREATE TABLE instructor_grading_queue (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  instructor_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  course_id UUID REFERENCES courses(id) ON DELETE CASCADE,
  assignment_id UUID REFERENCES lessons(id) ON DELETE CASCADE,
  pending_submissions INT DEFAULT 0,
  oldest_submission_date TIMESTAMP WITH TIME ZONE,
  assignment_due_date TIMESTAMP WITH TIME ZONE,
  last_updated TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Course Analytics (cache for performance)
CREATE TABLE course_analytics_cache (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  course_id UUID REFERENCES courses(id) ON DELETE CASCADE UNIQUE,
  total_students INT DEFAULT 0,
  active_students INT DEFAULT 0,
  avg_progress DECIMAL(5,2) DEFAULT 0,
  completion_rate DECIMAL(5,2) DEFAULT 0,
  engagement_score DECIMAL(5,2) DEFAULT 0,
  at_risk_students INT DEFAULT 0,
  last_calculated TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Instructor Dashboard Preferences
CREATE TABLE instructor_dashboard_preferences (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  instructor_id UUID REFERENCES profiles(id) ON DELETE CASCADE UNIQUE,
  dashboard_view TEXT CHECK (dashboard_view IN ('card', 'list', 'activity')) DEFAULT 'card',
  show_grading_queue BOOLEAN DEFAULT TRUE,
  show_analytics BOOLEAN DEFAULT TRUE,
  show_upcoming_deadlines BOOLEAN DEFAULT TRUE,
  show_recent_activity BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Instructor Activity Feed
CREATE TABLE instructor_activity_feed (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  instructor_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  course_id UUID REFERENCES courses(id) ON DELETE CASCADE,
  activity_type TEXT CHECK (activity_type IN ('submission', 'discussion', 'enrollment', 'completion', 'question')) NOT NULL,
  student_id UUID REFERENCES profiles(id),
  related_item_id UUID,
  activity_text TEXT NOT NULL,
  activity_date TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  read BOOLEAN DEFAULT FALSE
);
```

### Existing Tables to Modify:
