# Student Dashboard Competitive Research Report
**Date:** May 3, 2026  
**Platforms Analyzed:** Canvas LMS, Moodle, TalentLMS  
**Current Platform:** SLA LMS (She Leads Africa)

---

## Executive Summary

This report analyzes student dashboard features across three leading LMS platforms (Canvas, Moodle, TalentLMS) to identify gaps and opportunities for improving the SLA LMS student experience. The research reveals **5 critical gaps** and **3 unnecessary features** that should be addressed to bring our student dashboard to competitive standards.

**Current Grade: B- (75/100)**  
**Target Grade: A (92/100)**

## 1. Platform Feature Comparison

### Canvas LMS Student Dashboard

**Core Features:**
1. **Multiple Dashboard Views**
   - Card View (visual course cards)
   - List View (agenda-style to-do list)
   - Recent Activity View (activity feed)
   - User can switch between views based on preference

2. **Comprehensive Sidebar**
   - To-Do List (up to 7 upcoming items)
   - Recent Feedback section (last 4 weeks)
   - View Grades button (quick access)
   - Shows items from ALL courses, not just favorites
   - Items auto-remove after submission
   - Manual removal for non-submission assignments

3. **Smart To-Do Management**
   - Displays ungraded quizzes
   - Shows assignments without online submission
   - Course announcements included
   - Each item shows: name, course, points, due date
   - Items persist for 4 weeks after due date
   - Icons differentiate assignment types

4. **Course Cards**
   - Visual course representation
   - Quick access to favorited courses
   - Course nicknames support
   - Color-coded organization

5. **Global Announcements**
   - Institution-wide announcements
   - Dismissible with archive access
   - Prominent placement

### Moodle Student Dashboard

**Core Features:**
1. **Timeline Block (Primary Widget)**
   - Overview of all deadlines
   - Shows activities with due dates
   - "Remind me to grade by" for instructors
   - Displays max 2 weeks of overdue items
   - Shows 5 activities per course (oldest first)
   - "Show more activities" for additional items

2. **Calendar Integration**
   - Full calendar view
   - Event tracking
   - Due date visualization
   - Course event integration

3. **Recently Accessed Items Block**
   - Quick access to recent content
   - Cross-course visibility
   - Activity-based tracking

4. **Customizable Dashboard**
   - Users can add/remove blocks
   - Drag-and-drop positioning
   - "Reset to default" option
   - Admin can set default blocks for all users

5. **Course Overview**
   - All enrolled courses visible
   - Progress indicators
   - Quick navigation

### TalentLMS Student Dashboard

**Core Features:**
1. **Modern Interface**
   - Fresh, clean design
   - Improved navigation
   - Mobile-responsive

2. **Course Progress Tracking**
   - Visual progress bars
   - Completion percentages
   - Estimated completion dates

3. **Certifications & Badges**
   - Progress tab for tracking awards
   - Certificate display
   - Badge showcase
   - Motivation through gamification

4. **Dashboard Widgets**
   - Customizable for learners
   - Personalized learning paths
   - Quick course access

5. **Legacy/New Interface Toggle**
   - Users can switch interfaces
   - Preference remembered
   - Smooth transition

## 2. Current SLA Student Dashboard Analysis

### ✅ What We Do Well

1. **Visual Design**
   - Modern, clean interface
   - Good use of whitespace
   - Professional typography
   - Responsive layout

2. **Progress Tracking**
   - Progress bars on courses
   - Percentage completion

3. **Personalization**
   - Time-of-day greeting
   - Career goal display
   - First name usage

4. **Course Organization**
   - In Progress / Completed tabs
   - Clear course cards
   - Resume/Start CTAs

5. **Sidebar Widgets**
   - "Next up" widget
   - Learning plan calendar
   - Quick links

### ❌ Critical Gaps (Missing Features)

#### Gap 1: No Comprehensive To-Do List ⚠️ HIGH PRIORITY
**What's Missing:**
- No centralized to-do list showing ALL upcoming assignments/deadlines
- No visibility into assignments across all courses
- Students must visit each course individually to see what's due

**Competitor Implementation:**
- **Canvas:** Sidebar shows up to 7 upcoming items with due dates, points, course name
- **Moodle:** Timeline block shows all deadlines, max 5 per course with "show more"
- **TalentLMS:** Dashboard widgets show upcoming tasks

**Impact:** Students miss deadlines, poor time management, increased support requests

**Recommendation:** Add a "To-Do List" widget showing:
- Next 7 upcoming assignments/quizzes across all courses
- Due date, course name, points
- Icons for assignment types
- Manual dismiss option
- Auto-remove after submission

---

#### Gap 2: No Recent Feedback Section ⚠️ HIGH PRIORITY
**What's Missing:**
- No way to see which assignments have been graded
- No notification of new feedback
- Students must check each course individually

**Competitor Implementation:**
- **Canvas:** "Recent Feedback" section shows graded assignments from last 4 weeks
- **Moodle:** Recently accessed items includes graded work
- **TalentLMS:** Progress tracking includes feedback visibility

**Impact:** Students miss instructor feedback, reduced engagement, delayed improvement

**Recommendation:** Add "Recent Feedback" widget showing:
- Assignments graded in last 4 weeks
- Grade received
- Link to view feedback
- Course identification

---

#### Gap 3: No Calendar/Timeline Integration ⚠️ MEDIUM PRIORITY
**What's Missing:**
- Calendar widget exists but is not functional
- No integration with course deadlines
- No event tracking
- "Set your learning plan" link goes nowhere

**Competitor Implementation:**
- **Canvas:** Full calendar integration with events and deadlines
- **Moodle:** Timeline block + Calendar block work together
- **TalentLMS:** Dashboard shows upcoming events

**Impact:** Poor planning, missed deadlines, no holistic view of commitments

**Recommendation:** 
- Make calendar functional with real course deadlines
- Add ability to add personal events
- Highlight days with deadlines
- Integrate with to-do list

---

#### Gap 4: No Global Announcements ⚠️ MEDIUM PRIORITY
**What's Missing:**
- No way to display institution-wide announcements
- No communication channel for important updates
- No dismissible notification system

**Competitor Implementation:**
- **Canvas:** Global announcements at top of dashboard, dismissible
- **Moodle:** Announcements block available
- **TalentLMS:** Admin can post platform-wide updates

**Impact:** Students miss important institutional updates, poor communication

**Recommendation:** Add global announcements section:
- Dismissible cards
- Archive for dismissed announcements
- Admin control over visibility
- Expiration dates

---

#### Gap 5: No Dashboard View Options ⚠️ LOW PRIORITY
**What's Missing:**
- Only one dashboard layout available
- No user preference for different views
- No list view or activity feed option

**Competitor Implementation:**
- **Canvas:** 3 view options (Card, List, Recent Activity)
- **Moodle:** Customizable blocks, drag-and-drop
- **TalentLMS:** Widget customization

**Impact:** One-size-fits-all approach doesn't suit all learning styles

**Recommendation:** 
- Add List View option (agenda-style)
- Add Recent Activity View option
- Remember user preference
- Keep current Card View as default

---

### 🗑️ Unnecessary Features (Should Remove/Simplify)

#### Unnecessary 1: Non-Functional Calendar Widget
**Current State:**
- Calendar displays but doesn't show any events
- "Set your learning plan" link is broken
- Month navigation works but serves no purpose
- Takes up valuable sidebar space

**Recommendation:** 
- Either make it functional (Gap 3) OR remove it entirely
- Don't show broken features to users

---

#### Unnecessary 2: Overly Prominent Onboarding Banner
**Current State:**
- Large banner for incomplete onboarding
- Takes up significant space
- Shown even after user has engaged with platform
- Distracting from main content

**Recommendation:**
- Make banner smaller and less intrusive
- Auto-dismiss after 3 logins
- Move to sidebar or top notification area
- Only show for truly incomplete profiles

---

#### Unnecessary 3: Help Bubble (Hidden on Mobile)
**Current State:**
- Fixed help button in bottom right
- Hidden on mobile (where most users are)
- No clear purpose or functionality
- Takes up screen real estate

**Recommendation:**
- Remove fixed help bubble
- Add help link to user menu instead
- Or make it functional with actual help content

## 6. Database Schema Changes Needed

### New Tables Required:

```sql
-- To-Do Items (for manual user-created tasks)
CREATE TABLE user_todo_items (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  description TEXT,
  due_date TIMESTAMP WITH TIME ZONE,
  completed BOOLEAN DEFAULT FALSE,
  dismissed BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Global Announcements
CREATE TABLE global_announcements (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  title TEXT NOT NULL,
  content TEXT NOT NULL,
  priority TEXT CHECK (priority IN ('low', 'medium', 'high')) DEFAULT 'medium',
  start_date TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  end_date TIMESTAMP WITH TIME ZONE,
  created_by UUID REFERENCES profiles(id),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Dismissed Announcements (track which users dismissed which announcements)
CREATE TABLE dismissed_announcements (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  announcement_id UUID REFERENCES global_announcements(id) ON DELETE CASCADE,
  dismissed_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  UNIQUE(user_id, announcement_id)
);

-- User Dashboard Preferences
CREATE TABLE user_dashboard_preferences (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE UNIQUE,
  dashboard_view TEXT CHECK (dashboard_view IN ('card', 'list', 'activity')) DEFAULT 'card',
  show_onboarding_banner BOOLEAN DEFAULT TRUE,
  onboarding_banner_dismissals INT DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Calendar Events (personal events students can add)
CREATE TABLE user_calendar_events (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  description TEXT,
  event_date TIMESTAMP WITH TIME ZONE NOT NULL,
  event_type TEXT CHECK (event_type IN ('personal', 'study', 'deadline', 'other')) DEFAULT 'personal',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
